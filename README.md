# MNC BD 情报库

全球 Top 20 跨国药企（MNC）的 **BD / 研发 / 投资负责人情报库** —— 纯静态站点，无需后端、无需数据库。

**在线访问**：https://yangliu9revir.github.io/MNC_BD/

另有一个单文件离线版 `MNC_BD.html`（Logo 已内联），可直接下载给同事双击使用。

- **上传照片识人**：本机人脸向量比对（366 张头像建索引，361 人可用），支持离线使用

## 技术栈

- **纯静态**：HTML + 原生 JavaScript，无后端、无数据库、无构建依赖，可直接托管在 GitHub Pages
- **d3 v7**：人物关系网络图的力导向布局（本地 vendored，UMD 版）
- **face-api.js**（MIT）：人脸检测与 128 维特征比对，3 个模型文件全部本地按需加载

## 本地预览

```bash
# 推荐：起个静态服务（人脸识别在 file:// 下无法加载模型）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

直接双击 `index.html` 也能打开绝大部分功能，但**「上传照片识人」会提示资源加载失败**——浏览器在 `file://` 协议下会拦截模型文件请求，这是浏览器的安全策略，不是站点问题。需要人脸识别就用上面的 http 方式，或直接用 `MNC_BD.html`（离线单文件版，配合同级目录的 `models/` 使用）。

首次点击「本机识别人脸」会下载约 8MB 模型，之后由浏览器缓存；首页加载不受影响。

## 关于本仓库

这是**部署产物仓库**：内容由主项目构建后同步而来，**请不要在这里直接修改文件**。

更新流程：

1. 在主项目里修改数据或页面
2. 若改动了 `index.html` / `data.js` / `network.js`，先跑 `node build_standalone.js` 重建单文件版
3. 若更换了头像，需重建人脸索引（`node research/build_face_index.js`）
4. 同步到本目录后提交推送：

```bash
# 在主项目根目录执行
cd /path/to/MNC_BD
rsync -a --exclude='.DS_Store' index.html data.js network.js face_index.js MNC_BD.html \
      vendor logos photos models github_release/MNC_BD/
cd github_release/MNC_BD && git add -A && git commit -m "内容更新" && git push
```
